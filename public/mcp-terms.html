CCFDDL Plugin Terms

Effective September 30, 2026.

The CCFDDL plugin provides public research conference data for information only. Conference organizers may change deadlines. Check the linked official conference website before making submission decisions.

The plugin is read-only. It cannot submit papers, edit CCFDDL data, access private favorites, or send reminders. Availability and accuracy are not guaranteed.

CCFDDL source code and data in the project repository are provided under the repository's MIT License. These terms do not change that license.
