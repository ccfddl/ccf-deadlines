CCFDDL Plugin Privacy Policy

Effective September 30, 2026.

The CCFDDL plugin accepts conference names, subject categories, ranks, and time windows from a user's ChatGPT request to search our public conference dataset. It does not require a CCFDDL account or access favorites, email addresses, or reminder settings.

Queries are processed to produce a response. The plugin does not store queries or results in its application database. It does not sell personal data. The MCP service runs on Cloudflare Workers, which processes network information such as IP addresses and request metadata to deliver and protect the service. OpenAI also processes plugin calls as part of ChatGPT under its own privacy terms.

CCFDDL retains no application-level query history. Infrastructure providers may retain operational records under their own retention policies. If you file a support issue, GitHub retains the information you choose to post under its policies; you can edit or delete that issue through GitHub.

For privacy questions, contact the maintainers through GitHub Issues. Please do not post sensitive personal data in a public issue.
